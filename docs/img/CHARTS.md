# Charts

`hero.png` / `hero.svg` (the README chart) is generated by `python3 docs/img/make_hero_chart.py`: compressed size as
a percentage of xz -9e for QZip, mcm, xz and zstd on enwik8 and five public CSVs.

## Launch charts

PNG (170 dpi) and SVG of each chart, generated by `python3 docs/img/make_launch_charts.py` from measured, byte-exact
results only (numbers and caveats: `bench/LAUNCH_FACTS.md`).

| file | caption |
|---|---|
| `enwik8_size_vs_speed` | enwik8 (100 MB Wikipedia): QZip default 17.36 MB in 44 s vs mcm 17.54 MB, QZip --max (x18) 17.26 MB in 144 s, xz -9e 24.83 MB, zstd -19 26.50 MB. |
| `enwik9_size_vs_speed` | enwik9 (1 GB): QZip default 136.85 MB in 6.2 min vs mcm 138.57 MB in 5.6 min and x18 137.08 MB in 21.6 min. |
| `csv_ratio` | Real CSVs: QZip default is 20–26% smaller than mcm and 1.65–3.8× smaller than xz -9e. |

Hardware for all points: one shared i9-14900KF desktop, nice 19, single-threaded coders. The xz/zstd/libbsc enwik8 times
come from an earlier, more loaded session. The full benchmark charts (logs, NIfTI, RAM) are in `docs/charts/`.
